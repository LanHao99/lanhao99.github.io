*Galant schemata – summary*

## Openings (presentations)｜开端（呈示）

The following schemata tend to appear at the opening of themes, often as the framework for a presentation phrase in a [sentence](/posts/music/form/theme-types/sentence/).

以下程式倾向于出现在主题的开头，常常作为[乐句式](/posts/music/form/theme-types/sentence/)中呈示乐句的框架。

\*Note: though these schemata are presented in major mode, most of these can be converted directly to minor mode.

\*注：尽管这些程式是以大调式呈现的，但其中大多数都可以直接转换为小调式。

### The Do–Re–Mi｜Do–Re–Mi 程式

Though common in a three-stage version, this four-stage version is more typical when employed in a presentation phrase.

尽管三阶段版本也很常见，但用在呈示乐句中时，这一四阶段版本更具典型性。

| stage: 阶段 | 1 | 2 | 3 | 4 |
| ---: | :---: | :---: | :---: | :---: |
| melody: 旋律 | *do* | *re* | *re* | *mi* |
| bass: 低音 | *do* | *ti* | *ti* | *do* |
|  |  |  |  |  |
| thoroughbass: 数字低音 | 5/3 | 6/5 | 6/5 | 5/3 |
| Roman numerals: 罗马数字 | I | V | V | I |
| functions: 功能 | T | D | D | T |

(Root-position dominant chords may also be used.)

（也可以使用原位属和弦。）

### The Romanesca｜罗马内斯卡程式（The Romanesca）

| stage: 阶段 | 1 | 2 | 3 | 4 |
| ---: | :---: | :---: | :---: | :---: |
| melody: 旋律 | *sol* | *sol* | *do* | *sol* |
| bass: 低音 | *do* | *ti* | *la* | *mi* |
|  |  |  |  |  |
| thoroughbass: 数字低音 | 5/3 | 6/3 | 5/3 | 6/3 |
| Roman numerals: 罗马数字 | I | V | VI | I |
| functions: 功能 | T | D | Tx | T |

The melody of this schema is quite flexible. The bass/harmony are the more definitive elements. Also note that, in contrast to the other “presentation” schemata, this schema is far more common in slower movements.

这一程式的旋律相当灵活。低音／和声才是更具界定性的要素。还要注意，与其他"呈示"程式相比，这一程式在较慢的乐章中要常见得多。

### The Modulating Prinner｜转调的普林纳程式

This schema modulates from the tonic to the dominant. It is a common continuation phrase for a modulating sentence. It is also a common framework for a *tutti* passage that begins the transition module of a sonata/symphony movement.

这一程式从主调转调至属调。它是转调乐句式常见的继续乐句。它也是开启奏鸣曲／交响曲乐章连接模块的*全奏*（tutti）段落常用的框架。

| stage: 阶段 | 1 | 2 | 3 | 4 |
| ---: | :---: | :---: | :---: | :---: |
| melody: 旋律 | *mi* | *re* | *do* | *ti* |
| bass: 低音 | *do* | *ti* | *la* | *sol* |
|  |  |  |  |  |
| thoroughbass: 数字低音 | 5/3 | 6/3 | 7–#6/3 | 5/3 |
| Roman numerals: 罗马数字 | I | V | VII/V | V |

or

或

| stage: 阶段 | 1 | 2 | 3 | 4 | 5 |
| ---: | :---: | :---: | :---: | :---: | :---: |
| melody: 旋律 | *mi* | *re* | *do* | *do* | *ti* |
| bass: 低音 | *do* | *ti* | *la* | *re* | *sol* |
|  |  |  |  |  |  |
| thoroughbass: 数字低音 | 5/3 | 6/3 | 7–#6/3 | 7/# | 5/3 |
| Roman numerals: 罗马数字 | I | V | VII/V | V/V | V |

### The Passo Indietro｜Passo Indietro 程式

| stage: 阶段 | 1 | 2 |  |  |
| ---: | :---: | :---: | --- | --- |
| melody: 旋律 | *la* | *sol* |  |  |
| bass: 低音 | *fa* | *mi* |  |  |
|  |  |  |  |  |

| Roman numerals: 罗马数字 | IV | I |  |  |
| functions: 功能 | S | T |  |  |

This is essentially the first two stages of a Prinner. The latter two stages are often elided (cut away) in order to make room for a cadence pattern.

这本质上是 Prinner 的前两个阶段。后两个阶段常被省略（切去），以便为终止式样式腾出空间。

Like the Prinner, the Passo Indietro has a “modulating version” (the first two stages of the Modulating Prinner).

与 Prinner 一样，Passo Indietro 也有一个"转调版本"（即转调 Prinner 的前两个阶段）。

### The fa–fi–sol HC｜fa–fi–sol 半终止

This is a common approach to a half cadence, especially at the end of a sonata movement’s transition (TR) module. The definitive element is the bass line: *fa*–*fi*–*sol*. The *re*–*do*–*ti* melody is common, and the most active of the possibilities that fit the harmonies. See Mozart’s K. 545, I., mm. 10–11, and K. 333, I., mm. 17–18, for examples.

这是走向半终止的一种常见方式，尤其在奏鸣曲乐章连接（TR）模块的末尾。其界定性要素是低音线：*fa*–*fi*–*sol*。*re*–*do*–*ti* 的旋律很常见，也是与这些和声相配的各种可能中最具运动感的一种。实例见莫扎特 K. 545 第一乐章第 10–11 小节，以及 K. 333 第一乐章第 17–18 小节。

| stage: 阶段 | 1 | 2 | 3 |
| ---: | :---: | :---: | :---: |
| melody: 旋律 | *re* | *do* | *ti* |
| bass: 低音 | *fa* | *fi* | *sol* |
|  |  |  |  |
| thoroughbass: 数字低音 | 6/3 | 6/5 | (7) |
| Roman numerals: 罗马数字 | II | V/V | V |
| functions: 功能 | S | S | D |

| stage: 阶段 | 1 | 2 |
| ---: | :---: | :---: |

(The Compound HC can be approached by any **S** chord, or even the end of the tonic prolongational zone.)

（复合半终止可以由任何 **S** 和弦引入，甚至可以由主音延长区的末端引入。）

There are, of course, more cadence patterns than these, but these are the most straightforward for framing an improvisation, or a simple model composition. See [Classical cadence types](http://openmusictheory.com/cadenceTypes.html) for more details about standard cadential patterns.

当然，终止式样式远不止这些，但这些是用于搭建即兴或简单示范性写作最为直接的几种。关于标准终止式样式的更多细节，参见 [Classical cadence types](http://openmusictheory.com/cadenceTypes.html)。
