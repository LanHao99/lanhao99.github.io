# 场景的写法

延伸阅读：[十步雪花写作法](/posts/写作/十步雪花写作法/)

## 场景结构的两个层次

场景结构可从两个层次理解：大纲层面的场景推进，以及细纲层面的段落推进。

在讨论结构前，先要知道“完美”如何衡量：答案取决于读者为什么阅读。读者阅读小说，是为了获得强烈的情感体验。爱情小说要让读者仿佛正在坠入爱河；惊悚小说要让读者仿佛身临致命危险；奇幻小说要让读者仿佛进入一个陌生、奇妙而有魔力的世界。

## 场景大纲：场景与续集

德怀特·斯旺将普通意义上的“场景”分为两种结构：**场景（Scene）**与**续集（Sequel）**。两者交替出现，形成持续的故事推进。

### 场景：目标、冲突、灾难

场景具有三部分模式：

1. Goal：目标；
2. Conflict：冲突；
3. Disaster：灾难。

设计一个主动场景时，可逐项回答：

1. **POV 角色**：这一场对谁的风险或损失最大？
2. **本场目标**：能否用一句话说明，并明确判断成败？
3. **场景熔炉（Scene Crucible）**：此时此地有哪些因素阻止他达成目标？包括环境、他人和自身弱点。
4. **冲突设计**：角色会依次尝试哪些办法？每个办法遇到什么阻力？张力如何逐层升级？
5. **结局**：这是挫败还是胜利？能否形成“挫败结尾”或“胜利中带隐患”？结尾是否留下开放回路，让读者必须知道下一步怎么办？

### 续集：反应、困境、决策

续集也有三部分模式：

1. Reaction：反应。灾难发生后，先展示视角角色不受控制的情绪反应，再进入行动。
2. Dilemma：困境。让角色面对多个糟糕选项，最终不得不选择相对不坏的一条。
3. Decision：决策。让角色做出有驱动力、体现主观能动性的选择。

设计一个反应场景时，可逐项回答：

1. **POV 角色**：通常是刚受挫的人，或受挫影响最大的人。
2. **上一场的挫败**：明确写出是什么，避免场景脱节。
3. **反应的呈现**：他或她会有哪些身体反应、行为或心理闪回？需要几行或几段？
4. **困境**：有哪些选项？哪一个最能体现价值观冲突？
5. **决策**：最终选择哪条路、为什么？这个决定将变成哪个主动场景的目标？能否让它既危险又合情合理？
6. **篇幅判断**：这个反应真的需要完整一场吗？还是可用一两段总结带过，或在下一场主动场景中顺带交代？

场景中的目标、冲突和灾难都不可或缺。选定视角角色后，作者的任务是有说服力地展示他或她经历这一切，使读者感觉自己就是这个角色。

完整循环是：一个场景引出续集，续集的决策又引出新场景的目标。场景与续集不断交替，直到角色获得终极胜利或终极失败。

## 场景细纲：动机—反应单元

MRU 是 Motivation-Reaction Unit（动机—反应单元）。正确书写 MRU，是让小说具有吸引力的关键之一。

写作时交替描述：

- **动机**：POV 角色看到、听到或感受到的外部事物；
- **反应**：POV 角色的内部体验与随后的行动。

动机是外部、客观的；反应是内部、主观的。这样的交替能让读者产生正在亲历事件的错觉。

### 动机：外部且客观

动机可以用一句简洁、客观的话呈现。例如：

> 老虎从树上跳下来，向杰克扑去。

这像摄影机所见：没有任何内容表明我们已经进入杰克的主观视角。动机部分应保持简洁、清晰、干净。

### 反应：从快到慢

反应是内在且主观的，是把读者带进 POV 角色内心的机会。它不能与动机混在一起，并应遵循时间顺序。

看到老虎的最初几毫秒，杰克只有时间恐惧；在十分之几秒内，他可能做出本能反射；再之后才可能进行理性行动、思考或说话。因此，反应应按从最快到最慢的时间尺度呈现。

例如：

> 一股原始的肾上腺素瞬间冲过杰克全身。他猛地将步枪端到肩上，瞄准老虎的心脏，扣动了扳机。“死吧，你这个混蛋！”

这个反应包含三部分：

1. **感觉**：“一股原始的肾上腺素瞬间冲过杰克的身体。”它几乎瞬间发生，因此最先出现。
2. **反射**：“他猛地把步枪靠在肩上……”这是恐惧带来的本能反应，不需要有意识地思考。
3. **理性的行动和言语**：“瞄准老虎的心脏，扣动扳机……”角色已有时间思考并作出理性行动；说话则是强烈情感的理性表达。

可以省略其中一两部分，但余下部分仍必须按正确顺序排列：有情感时先写情感；有反射时绝不能早于情感；有理性行动时必须放在最后。

动机可以复杂也可以简单，唯一要求是**外部且客观**：不仅主角能看见、听见或感受，任何旁观者也能看见、听见或感受。

保持交替模式：先写一个动机，再写一个反应；再写一个动机，再写一个反应。当动机或反应用尽时，这个场景或续集也就结束了。

## 修改：先自由创作，再结构化诊断

严格按规则写作可能让人僵住。创作初稿时，可以先忘掉规则，按自己的方式写章节，接受它的无结构与不完美。写完后先放一段时间；编辑不是当下的任务。

开始第二稿时，再对每个场景做“急诊判断”。

### 给每个场景贴 Yes、No、Maybe 标签

- **Yes**：场景本身是一个小故事，读完有情绪冲击，而且能清楚说出它的场景熔炉。
- **No**：场景和主线无关、没有情绪、场景自身也没有故事，无论怎么修都救不活。
  - 不要立刻删除文件，先标为“待删除”，下一稿再统一物理删除。
- **Maybe**：感觉有用，但结构不对或力道不足，需要重写。

### 处理 Maybe 场景的流程

1. 判断它应当是**主动场景**还是**反应场景**。
   - 如果两者都说不通，大概率应标为 No。
2. 若是主动场景：
   - 补齐 POV、目标、冲突与挫败；
   - 写出这一场的场景熔炉。
3. 若是反应场景：
   - 问自己：这个反应真的需要一整场吗，还是一句话就够？
   - 若保留，补齐反应、困境、决策与场景熔炉。
4. 写清场景要带给读者的主导情绪：恐惧、心碎、希望、愤怒或紧张。

最后分析每一场：它是场景、续集，还是两者都不是？如果都不是，就设法把它变成其中之一，或将其舍弃。若是场景，就用一句话分别验证目标、冲突和灾难；若是续集，就分别验证反应、困境和决策。

重写时按 MRU 逐个检查：确保每个动机与反应之间用段落分隔。单个动机或反应可以占多个段落，但不要把两者混在同一段。清除既非动机也非反应的内容；让每个动机彻底客观、外部，让每个反应尽可能主观、内在，并始终维持“感觉 → 反射 → 理性行动与言语”的顺序。
